# Landing Page - Tributo a Freddie Mercury

Uma landing page responsiva dedicada à lenda do rock barroco, Freddie Mercury. Este projeto foi desenvolvido com foco em praticar a estruturação semântica em html e a estilização avançada com css puro.

## O Projeto e o Processo

O design e a identidade visual desta landing page foram criados do zero, unindo referências estéticas a um fluxo de trabalho estruturado:

*   **Inspiração e Referências:** pesquisa e curadoria de referências visuais no **Pinterest** para capturar a essência artística e extravagante de Freddie Mercury.
*   **Design e Moodboard:** desenvolvimento do layout e definição da paleta de cores (moodboard) utilizando o **Figma**.
*   **Tratamento de Imagens:** edição e corte dos assets visuais utilizando o **Canva** para garantir harmonia com o layout.

## Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica da página.
*   **CSS3:** Estilização moderna, layouts responsivos (Flexbox/Grid), tipografia, funções e personalização de elementos.
