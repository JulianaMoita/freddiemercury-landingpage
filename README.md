# 👑 Tributo a Freddie Mercury - Landing Page

Uma landing page responsiva dedicada ao lendário vocalista da banda Queen, Freddie Mercury. Este projeto foi desenvolvido com foco em praticar a estruturação semântica em **HTML5** e a estilização avançada com **CSS3 puro** (Vanilla CSS).

---

## 🎨 O Projeto & Processo Criativo

O design e a identidade visual desta landing page foram criados do zero, unindo referências estéticas a um fluxo de trabalho estruturado:

*   **Inspiração & Referências:** Pesquisa e curadoria de referências visuais no **Pinterest** para capturar a essência artística e extravagante de Freddie Mercury.
*   **Design & Moodboard:** Desenvolvimento do layout e definição da paleta de cores (moodboard) utilizando o **Figma**.
*   **Tratamento de Imagens:** Edição e corte dos assets visuais utilizando o **Canva** para garantir harmonia com o layout.

---

## 🚀 Tecnologias Utilizadas

*   **HTML5:** Estruturação semântica da página.
*   **CSS3:** Estilização moderna, layouts responsivos (Flexbox/Grid), tipografia e personalização de elementos.

---

## 🛠️ Como rodar o projeto localmente

1. Clone o repositório para a sua máquina:
   ```bash
   git clone https://github.com/JulianaMoita/freddiemercury-landingpage.git
   ```
2. Navegue até a pasta do projeto.
3. Abra o arquivo `index.html` diretamente em seu navegador ou utilize a extensão **Live Server** no VS Code para visualizar em tempo real.
